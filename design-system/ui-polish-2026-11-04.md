## 优先级与已实施方案

优先级表示本次 UI 优化的实施顺序。

| 优先级 | 问题与原因 | 已实施方案 | 主要代码 |
|---|---|---|---|
| P1 · 1 | 页头、分类、筛选和表格的间距不一致；信息起点偏低，跨页面缺少稳定节奏。 | 统一后台间距 token；普通页顶 24px、页头间隔 20px、普通表格纵向内边距 18→14px。服务器/节点继续使用局部 12px 密度；桌面控件与视图切换外框统一为 40px。 | `web/src/admin-console.css` 的页面、分类、工具栏与表格规则 |
| P1 · 2 | 服务器地址与区域各占一行，Agent、通讯方式和时间的层级弱，卡片底部操作缺少稳定基线。 | 地址/区域合并为可换行的信息行；资源指标、Agent 和时间各自成组；底部操作对齐。拆出 `MachineCard`，卡片与表格仍共用筛选和业务动作。 | `web/src/components/MachineCard.tsx`、`web/src/pages/ResourceListPage.tsx` |
| P2 · 3 | 手机节点的重复标签、上报和操作独占行增加滚动；平板总览指标 3+2 排布留空，手机排行空间不足。 | 节点名称提升为记录标题，上报与操作并排置底；降低通用手机表格选择器优先级，使局部布局正确生效。平板保留五列指标，手机两列加末项通栏；手机排行隐藏辅助序号，数值右对齐且单位不换行。 | `web/src/pages/NodesPage.tsx`、`web/src/components/ResourceList.tsx`、响应式 CSS |
| P2 · 4 | 中文字体回退不稳定，技术数值和手机字段标签偏小；未明确颜色的总览链接出现浏览器默认紫色。 | 明确 Windows/macOS/Linux 中文字体栈；常规技术数据 13px，手机字段标签 12px；后台链接继承主题颜色，资源入口 hover 增加下划线。服务器时间提高到 12px 并采用等宽数字。 | 后台字体、链接、卡片时间与移动记录规则 |
| P2 · 5 | 输入 hover/错误反馈不足；节点发布等待图标缺少尺寸和边框；滚动容器可能裁切切换控件的焦点框。 | 补齐输入 hover、错误背景/边框及错误焦点；列表错误独立成行。发布 spinner 固定 16px，加载按钮暴露 `aria-busy`；分类和视图切换采用内缩焦点框。手机管理员入口、返回及主要操作保持 44px 命中高度。 | `web/src/components/ui.tsx`、`web/src/pages/NodesPage.tsx`、后台状态 CSS |

以上五项均已实施。编辑区桌面分区内边距由 28→24px，字段纵横间距为 20/24px；手机保存栏减少多余内边距并保留安全区。没有通过缩小手机触控目标换取紧凑度。

## 代码与样式维护

- 直接调整既有 `admin-console.css` 规则，未追加第二套覆盖样式表；样式保持后台作用域。
- `MachineCard` 仅负责展示，保留隐藏地址、节点跳转、指标缺失值、升级文案和原操作入口。
- `ResourceDate` 增加语义样式类，节点最后上报增加局部类；未改变时间格式或版本判断。
- 通用按钮的 `aria-busy` 支持原调用方显式传值，加载时优先表达忙碌状态。
- 同步 `DESIGN.md` 和后台 surface brief；没有修改公共页面样式、API、协议或数据库。
- `web/dist` 已重新构建，为仓库现有跟踪的嵌入资源产物。后台、门户及共享受保护分块继续保留。
