# 浏览器检查证据

本目录截图使用独立 Vite 预览、演示数据或 Playwright 拦截 API 生成，没有连接生产面板。

- 尺寸：1440×1000、1024×1000、390×844。
- 29 个布局场景：服务器、节点、节点编辑、版本历史、订阅账号编辑、套餐编辑、权限组、系统设置、访问 IP、审计；包含桌面与手机浅色，以及服务器/节点编辑/历史的深色和平板布局。
- `browser-results.json` 保存每次检查的页面标题、横向溢出结果和脚本错误。
- 行为：历史恢复仅写草稿，版本和运行确认不改变；401 后同管理员重新登录保留内存输入，不自动重发，手动重试继续携带版本。
- `reauthentication-1440-light.png` 为登录过期提示；测试账号和全部配置均为演示值。

复现：在 `web` 启动 `npm run dev -- --port 14531 --strictPort`，使用安装 Playwright 且提供 Edge 的 Python 执行 `python -X utf8 design-system/audit-2026-11-04/browser_check.py`。若只复查行为，使用 `--behavior-only`，保留现有截图检查结果。

这是有限的视觉与行为检查。服务端事务、并发、记账、权限及实际内核重载由对应 Go/PostgreSQL 和 Corade 测试验证；这些截图不代表生产上线或长期压力测试。
